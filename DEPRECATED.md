# DEPRECATED — historical reference only

This branch is **unsupported** and retained purely as a historical record of the
`v1` line of SCRS. It receives:

- no bug fixes,
- no security backports,
- no dependency updates,
- no support of any kind.

Do not build against it. Active development happens on `main`, which targets the
extracted [`fff`](https://github.com/nanithefkuc/fff) and
[`cafft`](https://github.com/nanithefkuc/cafft) libraries and is published as a plain
(non-workspace) library crate.

Opening issues or pull requests against this branch is not useful; they will be closed.
